# Learning Path

## Stage 1: Foundations
- Linux basics
- Networking basics
- TCP/IP and ports
- HTTP concepts
- DNS basics

## Stage 2: Reconnaissance
- Host discovery
- Port scanning
- Service enumeration
- Banner analysis

## Stage 3: Web and Application Security
- HTTP request flow
- Forms and auth
- Parameter tampering
- Common vulnerabilities
- OWASP Top 10

## Stage 4: Reporting
- Summarize findings
- Document impact
- Recommend remediation
- Risk-scoring and severity

## Stage 5: Real-world workflow
- Scope definition
- Discovery
- Enumeration
- Risk review
- Final report creation
