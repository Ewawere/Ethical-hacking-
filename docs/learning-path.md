# Beginner learning path

## Phase 1: Foundations
- Linux basics
- Networking basics
- IP addresses and ports
- DNS and HTTP basics

## Phase 2: Reconnaissance
- host discovery
- port scanning
- service detection
- identifying open services

## Phase 3: Enumeration
- review service banners
- discover HTTP endpoints
- identify exposed app surfaces

## Phase 4: Web basics
- auth flow
- cookies and headers
- requests and parameters
- common vulnerabilities

## Phase 5: Reporting
- findings summary
- impact assessment
- remediation steps
- clear documentation

## Good practice
- keep scope tight
- document everything
- never test outside your own authorized environment
- focus on understanding the workflow before doing exploit work
